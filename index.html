📋 Guía de Configuración — Google Sheets
Paso 1 — Crear el Google Sheet

Crea un nuevo Google Sheet en sheets.google.com.
Copia el ID del Sheet desde la URL:
docs.google.com/spreadsheets/d/ESTE_ES_EL_ID/edit

Paso 2 — Crear el Apps Script

Ve a script.google.com → Nuevo proyecto.
Borra el código existente y pega el contenido del archivo "Google Apps Script — Backend API" que generé.
Reemplaza TU_SHEET_ID_AQUI con el ID copiado en el Paso 1.

Paso 3 — Inicializar las hojas

En el editor del Apps Script, selecciona la función initSheet en el menú desplegable y haz clic en Ejecutar.
Esto crea las hojas Servidores e Historial con los encabezados correctos.

Paso 4 — Publicar como Web App

En el Apps Script: Implementar → Nueva implementación.
Tipo: Aplicación web.
Ejecutar como: Yo (tu cuenta).
Quién tiene acceso: Cualquier usuario (o tu organización si usas Workspace).
Haz clic en Implementar y copia la URL generada.

Paso 5 — Conectar el Dashboard

Pega la URL copiada en el campo de configuración del dashboard (banner amarillo) y haz clic en Guardar y Conectar.
Luego usa el botón + Agregar Servidor para poblar los datos iniciales.
